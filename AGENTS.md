# AGENTS.md

Operating manual for agents. `README.md` explains design rationale (partly stale);
the docs below describe the current wiring. If a change does not fit a recipe, copy
the nearest existing module.

## Project

- One NixOS flake, `x86_64-linux` only: `apollo` (workstation) and `iso`
  (Calamares installer).
- flake-parts + import-tree + home-manager; Lix 2.96; `nixos-unstable`; unfree
  allowed.
- `flake.nix` is generated by flake-file. `outputs.nix` is the real entry point.
- Desktop: Plasma + niri, Noctalia, Catppuccin, zsh/fish, starship, yazi, tmux.

## Non-negotiables

- **Never edit `flake.nix`.** Edit `modules/repository/inputs.nix` and run
  `nix run .#write-flake`.
- **Feature options live only in `modules/options/`.** Implementations read
  `config.modules.*` and gate `config`, never `imports`.
- **`imports` must be a concrete list.** `imports = lib.mkIf ...` is a type error.
- **Profiles and roles use `lib.mkDefault`.** A host assignment wins; do not use
  `mkForce`. Roles are imported wholesale and are not toggles.
- **import-tree skips `_`-prefixed files and directories.** Import `_package.nix`
  and `_data.nix` explicitly where needed.
- **Home Manager is per-user.** Keep it in `homes/<name>/`; `users.<name>.homeModules`
  defaults to `homes/<name>/home.nix` when present. Do not add a shared
  `modules/home` tree.
- **Imports go downward, one level.** Cross-tree wiring lives in `outputs.nix` or
  `hosts/default.nix`. Use `self.outPath + "/..."` for root-relative paths; there
  is no `flakeRoot` special argument.
- **Do not change `stateVersion`** (`26.05` on both hosts) or commit plaintext
  secrets.

## Commands

| Goal | Command |
|---|---|
| Broad sanity check | `nix flake check --show-trace --fallback --no-build` |
| Quick apollo evaluation | `nix build .#nixosConfigurations.apollo.config.system.build.toplevel --dry-run` |
| Build apollo | `nix build .#nixosConfigurations.apollo.config.system.build.toplevel` |
| Build the ISO | `nix build .#nixosConfigurations.iso.config.system.build.isoImage` |
| Prove a change is inert | `nix eval .#nixosConfigurations.apollo.config.system.build.toplevel.drvPath` |
| Apply on apollo | `nh os switch` (from `~/nixos-config`) |
| Format | `nix fmt`; before handoff also `nix run nixpkgs#deadnix -- --edit .` and `nix run nixpkgs#statix -- fix .` |
| Regenerate `flake.nix` | `nix run .#write-flake` |

There is no test suite. Evaluation, builds, and identical `drvPath` values are the
verification tools.
